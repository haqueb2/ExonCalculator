# ExonCalculator

A shell pipeline that retrieves exon structure and CDS information for a list of human gene symbols. For each gene, the pipeline queries UCSC's `ncbiRefSeqSelect` table (hg38) for all candidate transcripts, confirms MANE Select / MANE Plus Clinical status via NCBI GenBank, and produces a single joined output CSV containing only MANE-designated transcripts.

The schema for the `ncbiRefSeqSelect` table can be found [here](https://genome.ucsc.edu/cgi-bin/hgTables?db=hg38&hgta_group=genes&hgta_track=refSeqComposite&hgta_table=ncbiRefSeqSelect&hgta_doSchema=describe+table+schema).

Please note that the results generated by this code were utilized as part of ongoing projects at the Hospital for Sick Children (SickKids Hospital) by students in the Costain lab.

## Pipeline overview

```
input/gene_names.txt
        │
        ▼
 exon_length.sh  ──── UCSC MySQL (hg38 ncbiRefSeqSelect) ────►  output/ExonLength_output.csv
        │
        ▼
  CDSfinder.sh   ──── NCBI EDirect (GenBank flatfile)    ────►  output/CDS_output.csv
        │                (MANE Select filter applied here)
        ▼
ExonCalculator.sh ─── join on transcript_id              ────►  output/ExonCalculator_output.csv
```

### Script roles

| Script | Input | What it does | Output |
|---|---|---|---|
| `exon_length.sh` | `input/gene_names.txt` | Issues a single batched `IN (...)` query to UCSC MySQL for all genes; computes per-exon lengths | `output/ExonLength_output.csv` |
| `CDSfinder.sh` | `output/ExonLength_output.csv` | Fetches each transcript's GenBank record from NCBI; reads the `KEYWORDS` section to confirm MANE Select or MANE Plus Clinical status; skips all other transcripts | `output/CDS_output.csv` |
| `ExonCalculator.sh` | both outputs above | Orchestrates the two scripts above then joins their outputs on `transcript_id` | `output/ExonCalculator_output.csv` |

## Installation

### 1. MySQL client (macOS)

MySQL 9.x is **not compatible** with UCSC's remote server — it removed the `mysql_native_password` authentication plugin that UCSC requires. Install MySQL client 8.x via Homebrew:

```bash
brew install mysql-client@8.3
```

Update the `mysql_cmd` variable in `exon_length.sh` to point to the installed binary (e.g. `/usr/local/Cellar/mysql-client/8.3.0/bin/mysql`).

### 2. NCBI EDirect

```bash
sh -c "$(wget -q https://ftp.ncbi.nlm.nih.gov/entrez/entrezdirect/install-edirect.sh -O -)"
export PATH=${HOME}/edirect:${PATH}
```

Add the `export PATH` line to your `~/.zshrc` or `~/.bashrc` to make it permanent.

### 3. Scripts

Clone the repository and make the scripts executable:

```bash
git clone https://github.com/haqueb2/ExonCalculator.git
cd ExonCalculator
chmod +x ExonCalculator.sh exon_length.sh CDSfinder.sh
```

## Usage

1. Add gene symbols (one per line) to `input/gene_names.txt`:

```
ISG15
AGRN
B3GALT6
```

2. Run the pipeline:

```bash
./ExonCalculator.sh
```

Results are written to the `output/` directory.

## Output

### `output/ExonCalculator_output.csv` (final joined output)

Column | Description
--- | ---
`transcript_id` | RefSeq accession number (NM_…)
`gene` | HGNC gene symbol
`mane_status` | `MANE Select` or `MANE Plus Clinical`
`chrom` | Chromosome (e.g. `chr1`)
`strand` | `+` or `-`
`txStart` | Transcript start position in hg38 (0-based)
`txEnd` | Transcript end position in hg38
`cdsStart` | CDS start position from UCSC (genomic coordinates)
`cdsEnd` | CDS end position from UCSC (genomic coordinates)
`CDS_start` | CDS start position from NCBI GenBank (mRNA-relative, 1-based)
`CDS_end` | CDS end position from NCBI GenBank (mRNA-relative)
`CDS_length` | CDS length in bp (CDS_end − CDS_start)
`exonCount` | Number of exons
`exonStarts` | Semicolon-separated exon start positions (genomic, 0-based)
`exonEnds` | Semicolon-separated exon end positions (genomic)
`exonLengths` | Semicolon-separated exon lengths in bp
`exonFrames` | Semicolon-separated reading frame offsets {0, 1, 2} or −1 if non-coding

### Intermediate outputs

- `output/ExonLength_output.csv` — raw UCSC query results (all candidate transcripts for queried genes)
- `output/CDS_output.csv` — NCBI CDS positions for MANE-confirmed transcripts only
